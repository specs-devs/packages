# Friend Finder iOS Companion App

This is the companion iPhone app for the **Friend Finder** SPECS Lens. It bonds to the Lens over SPECS Mobile Kit, acquires the phone’s GPS/heading, and can share location phone-to-phone via MultipeerConnectivity.

## Requirements

- macOS with **Xcode 15** or newer
- An **iPhone running iOS 17+** (the app needs Bluetooth, CoreLocation, and MultipeerConnectivity)
- A free or paid **Apple Developer account** for code signing
- The `SpectaclesKit` Swift package is already included at `iOS/SpectaclesKit/`

## Generate the Xcode project

If you edit `project.yml` or move files, regenerate the project:

```bash
cd iOS
xcodegen generate
```

> **Note:** `FriendFinder.xcodeproj` is a generated file. Do not hand-edit it; edit `project.yml` instead.

## Build and run

1. **Open the project**
   ```bash
   open iOS/FriendFinder.xcodeproj
   ```

2. **Set your team**
   - Select the `FriendFinder` target → **Signing & Capabilities**
   - Set **Team** to your Apple Developer account
   - If needed, change **Bundle Identifier** to something unique (e.g. `com.yourname.friendfinder`)

3. **Build for your iPhone**
   - Select your connected iPhone as the run destination
   - Press **Run** (⌘R)

4. **Trust the developer profile on the phone**
   - First run: **Settings → General → VPN & Device Management → Trust**

## Using the app

The app has two roles. Use two iPhones in a crowd: one as **User** and one as **Friend**.

### User phone (bonds to SPECS)

1. In Lens Studio, push the **FriendFinder** Lens to your SPECS.
2. On the User iPhone, open the app and select **User**.
3. Tap **Bond to Lens**. This opens Snapchat, which returns the bonding deeplink to the app.
4. Once a bonding appears in the picker, select it and tap **Start Session**.
5. Pair with the Friend phone (it will connect automatically over Multipeer).
6. Put on SPECS; the AR arrow points toward the friend.

### Friend phone

1. Open the app and select **Friend**.
2. Keep the app open or in the background.
3. The phone advertises its GPS location to the User phone.

## Modes supported

| Lens mode | How self-location is sourced | How friend location is sourced |
|---|---|---|
| **GPS-on-SPECS** | SPECS `GeoLocation` | iOS app → Mobile Kit |
| **iPhone-centric** | iOS app → Mobile Kit (role: self) | iOS app → Mobile Kit (role: friend) |

Toggle `usePhoneLocation` on the `FriendFinderManager` script in Lens Studio to switch to iPhone-centric mode.

## Troubleshooting

| Problem | Fix |
|---|---|
| "Session is not available" in Lens Studio preview | Expected — Mobile Kit only works on physical SPECS + iPhone. |
| Bonding never appears | Make sure the Lens name in Lens Studio is **FriendFinder** and the phone is Bluetooth-paired with SPECS. |
| Phones don’t see each other | Both need Bluetooth + Wi-Fi enabled and be within ~30 ft. Multipeer works best when both phones are on the same Wi-Fi or have Wi-Fi enabled. |
| Xcode says `No such module 'SpectaclesKit'` | The local package is at `iOS/SpectaclesKit/`. If it was deleted, copy the `SpectaclesKit` folder from the SPECS Mobile Kit SDK back into `iOS/`. |
| Build fails on signing | Set a valid Apple Developer Team and unique bundle ID. |
